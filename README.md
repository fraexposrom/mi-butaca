# Mi Butaca

App para el móvil con tu historial de películas, series, anime y libros terminados.

- **Añadir** (botón central): eliges Película, Serie, Anime o Libro y rellenas sus datos.
- **Vistas**: películas, series y anime, con buscador, filtros y horas vistas.
- **Leídos**: libros agrupados por año, con páginas y libros del año.
- Toca cualquier elemento para editarlo o borrarlo.

Los datos no están aquí: se guardan en tu repositorio privado `mi-butaca-datos`, en el archivo `historial.json`. Funciona sin conexión y se instala en la pantalla de inicio.

Este repositorio es público porque GitHub Pages gratuito solo publica repositorios públicos. No contiene ningún dato tuyo.

## Cambiar el logo

En `iconos/opciones/` están las tres propuestas (1 · Butaca, la que va puesta; 2 · Palomitas; 3 · Claqueta). Para usar otra, copia los cuatro archivos de su carpeta (`logo.svg`, `icono-180.png`, `icono-192.png`, `icono-512.png`) dentro de `iconos/`, sustituyendo los que hay. Después borra el acceso directo del móvil y vuelve a añadirlo para que coja el icono nuevo.
