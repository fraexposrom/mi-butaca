          Clave de TMDB

          Para buscar portadas y datos de películas y series hace falta una clave gratuita de TMDB (The Movie Database). Solo se pide una vez: se guarda en tu repositorio de datos y llega sola a los demás móviles conectados a él.

          Cómo conseguirla (unos 5 minutos)
          1. Entra en themoviedb.org y pulsa «Únete a TMDB» (Join TMDB). Crea la cuenta y confirma tu correo: sin confirmar, la clave no funciona.
          2. Inicia sesión, toca tu foto (arriba a la derecha) › Ajustes (Settings) › API, en el menú de la izquierda.
          3. En «Request an API Key» elige Developer (uso personal) y acepta las condiciones.
          4. Rellena el formulario: tipo de uso Website; nombre Mi Butaca; dirección, la de tu app (https://TU-USUARIO.github.io/mi-butaca/); resumen: «App personal para llevar las películas y series que veo». Envíalo.
          5. En esa misma página verás la API Key (32 caracteres) y el API Read Access Token (muy largo). Copia cualquiera de los dos y pégalo aquí.

          Este producto usa la API de TMDB pero no está avalado ni certificado por TMDB.

          Renovar el token de GitHub

          1. En github.com, toca tu foto › Settings › Developer settings (abajo del todo) › Personal access tokens › Fine-grained tokens.
          2. Toca el token de Mi Butaca › Regenerate token. Elige la nueva caducidad y confirma. Mantiene el repositorio y los permisos.
          3. Copia el token nuevo (empieza por github_pat_). GitHub solo lo enseña una vez.
          4. Vuelve aquí, toca Pegar el token nuevo, pégalo, pon la nueva fecha de caducidad y pulsa Conectar.
